Build options can live under the top-level `"rbxts"` key of `tsconfig.json` instead of the command line. The merge order is defaults, then `rbxts`, then command-line flags.

The `rbxts` values merge through the `extends` chain from parent to child. Path values resolve relative to the file that declares them. Command-line values override tsconfig values. Sloptor warns about command-line-only values such as `watch`, `verbose`, and `usePolling` under `rbxts` and ignores them.

`nativeTypes` and the experimental `luauTypes` also read the top-level key of the same name in `rotor.toml`. A declared tsconfig value takes precedence, even an explicit `false`. Otherwise the `rotor.toml` value applies, and both unset means off. `luauTypes` also has a command-line flag, `--luauTypes`, which overrides both files.

## Source maps

Enable `compilerOptions.sourceMap` to write a `.luau.map` beside each Luau output:

```json
{
	"compilerOptions": {
		"sourceMap": true
	}
}
```

Source maps provide an anchor at generated column 0 on each mapped Luau line, plus segments where expressions, object fields, and source operators begin. Arithmetic, comparison, concatenation, logical, compound-assignment, and optional-chain operators point to their TypeScript tokens, including tokens on continuation lines. Generated and original columns use UTF-16 code units.

Binding names in declarations and parameters, punctuation, and synthesized literals don't get segments of their own. Compiler headers stay unmapped, and the maps have no `names` field. Maps describe the unminified output, so positions in `--minify` output don't match them. The compiler collects expression origins only with source maps on.

## Editor schema

The `rotor.toml` schema and the tsconfig `rbxts` schema are separate documents. Publish the `rbxts` one where your editors can read it:

```sh
sloptor schema --rbxts > rbxts-tsconfig.schema.json
```

Then point `tsconfig.json` at it:

```json
{
	"$schema": "./rbxts-tsconfig.schema.json",
	"rbxts": {
		"type": "game",
		"optimizedLoops": true
	}
}
```
