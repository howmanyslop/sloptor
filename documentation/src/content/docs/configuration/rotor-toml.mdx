`rotor.toml` at the project root configures optional native Flamework and experimental parallel external transformers. Add a schema directive for editor validation and completion:

```toml
#:schema https://raw.githubusercontent.com/howmanyslop/sloptor/main/rotor.schema.json
```

Need the schema offline? `sloptor schema > rotor.schema.json`.

This page is generated from `rotor.schema.json` when the site builds. A `<name>` segment is a table you name yourself, such as `[flamework.profiles.production]`.
