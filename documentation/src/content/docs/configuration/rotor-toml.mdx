`rotor.toml` at the project root holds the optional rotor settings. It sets the `//!native` type-annotation opt-in with `nativeTypes`. It also sets the experimental Luau opt-in with `luauTypes`, native Flamework, and parallel external transformers. Add a schema directive for editor validation and completion:

```toml
#:schema https://raw.githubusercontent.com/howmanyslop/sloptor/main/rotor.schema.json
```

Need the schema offline? `sloptor schema > rotor.schema.json`.

The site build generates this page from `rotor.schema.json`. A `<name>` segment is a table you name yourself, such as `[flamework.profiles.production]`.
