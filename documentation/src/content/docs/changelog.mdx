## How releases work

sloptor uses [bumpp](https://github.com/antfu-collective/bumpp) for versioning. Pushing a `vX.Y.Z` tag triggers a release, which cross-builds the binaries, smoke-tests them on every platform, and publishes the archives as a GitHub release.

`communique` writes the release notes. The release workflow then adds them to `CHANGELOG.md` and to this page.
